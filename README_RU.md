# TikTok Bro — Theos tweak

Исправленная версия прототипа статистики просмотров для **TikTok Lite**.

## Что исправлено

- Исправлен Bundle ID приложения: `com.ss.iphone.ugc.tiktok.lite`.
- Добавлен `TikTokBro.plist`, чтобы tweak загружался только внутри TikTok Lite.
- Поиск `AVPlayerLayer` теперь проходит по всему дереву слоёв и не обрабатывает один плеер несколько раз за тик.
- Идентификатор видео больше не зависит от текущего времени воспроизведения.
- Просмотр не засчитывается только из-за открытия ролика на отметке 75%: требуется реально просмотреть не менее 75% медиавремени.
- Перемотка вперёд/назад дисквалифицирует текущий просмотр; пауза и ускорение воспроизведения обрабатываются отдельно.
- Исправлена очистка устаревшего состояния, обновление дневного счётчика и защита от повторного открытия окна настроек.
- GitHub Actions устанавливает зависимости Theos и собирает два пакета: rootless и rootful.

## Сборка

1. Загрузите содержимое архива в репозиторий GitHub.
2. Откройте **Actions → Build TikTok Bro → Run workflow** либо отправьте commit в ветку `main`.
3. После завершения сборки скачайте artifact:
   - `TikTok-Bro-rootless` — для rootless jailbreak.
   - `TikTok-Bro-rootful` — для rootful jailbreak.

## Важно

Это **Theos tweak в формате `.deb`, а не IPA**. Он предназначен для jailbroken-устройств и не устанавливается через Sideloadly. Для установки через Sideloadly нужен отдельный IPA-проект с внедрённой модификацией.

Кнопка `TB` добавляется на экраны профиля, имена классов контроллеров которых содержат `Profile`. Поведение интерфейса и обнаружение плеера необходимо проверить на конкретной сборке TikTok Lite.
